**Q. Write a basic HTML program to create a webpage about “The Future of Technology” using the `<head>`, `<body>`, and `<footer>` tags. Add a heading, a paragraph containing bold, italic, and underlined text, and an image using the `<img>` tag.**

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Technology</title>
</head>
<body>

    <h1>The Future of Technology</h1>

    <p>
        Technology is changing the <i>way we live</i>,
        <b>transforming the future</b>, and
        <u>connecting the world</u>.
    </p>

    <img src="https://images.unsplash.com/photo-1518770660439-4636190af475" 
         alt="Technology">

    <footer>&copy; Tech World 2026</footer>

</body>
</html>
```
